# Architecture Decision Records (ADR)

Pliki ADR dokumentują ważne decyzje architektoniczne podjęte w projekcie.

## Konwencja nazewnictwa

```
ADR-NNN-krotki-opis.md
```

Przykład: `ADR-001-modular-task-architecture.md`

## Statusy

| Status | Znaczenie |
|---|---|
| **Proposed** | Propozycja, jeszcze nie zaakceptowana |
| **Accepted** | Zaakceptowana i obowiązująca |
| **Superseded** | Zastąpiona przez inną ADR (podać numer) |
| **Deprecated** | Wycofana bez następcy |
